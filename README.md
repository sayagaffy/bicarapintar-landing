## 🚦 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/YOUR_USERNAME/bicarapintar-landing.git
   cd bicarapintar-landing
   ```

Install dependencies
bashnpm install

Run development server
bashnpm run dev

Open in browser
http://localhost:3000

npm run dev # Start development server
npm run build # Build for production
npm run start # Start production server
npm run lint # Run ESLint
npm run export # Build and export static files
npm run static # Build static site for deployment
